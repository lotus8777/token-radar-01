How to read this

Implied value is the radar's own claim: TVL times a category multiple, adjusted for seven-day growth, for how long the protocol has run with no token, and for how many chains it is on. It is not a prediction that a token is issued, or when, or at what price. A protocol that records no token may still have one its DefiLlama record does not carry. Farm plans are a starting point, not financial advice: check the protocol's own pages before you put money in, and never pay anyone to claim an airdrop.

Data: DefiLlama protocols, fetched once and frozen. No network is used by this page.
